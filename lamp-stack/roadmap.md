## LAMP/LEMP Stack Roadmap (Linux, Apache/Nginx, MySQL, PHP)

### Backend (PHP + Laravel)
- PHP Basics: OOP, Error Handling
- Laravel: MVC, Eloquent ORM, Middleware
- Authentication: Sanctum, Passport
- Database: MySQL, Migrations
- Security: SQL Injection, CSRF, XSS
- Testing: PHPUnit
- Deployment: Apache/Nginx, Docker
